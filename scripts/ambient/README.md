| File | Source | Licence |

| `assets/audio/ambient-loop.m4a` | Original, generated by `ambient-generator.js` (D – Bm – G – Asus2 pad, 4 × 75 s) | Part of this project |
| `assets/audio/gregorian-chant.m4a` | “Introit – Resurrexi et adhuc tecum sum”, The Tudor Consort, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:The_Tudor_Consort_-_02_-_Introit_-_Resurrexi_et_Adhuc_Tecum_Sum.ogg) (sha1 `c14a8847c7b9cabff17ced255bf36acb3ff78612`) | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) — attribution shown in Settings |

Both tracks are 5:00, AAC 96 kbps, loudness-matched to −23 LUFS, and loop in the app.

## Regenerating the ambient loop

```bash
# 1. Render 5:00 + 20 s tail offline; the tail is folded onto the start so the loop is seamless
CHROME_PATH=/path/to/chrome node render-ambient.js <dir-containing-node_modules/playwright-core> /tmp/out

# 2. Measure loudness, then encode at -23 LUFS (adjust the gain to -23 minus the measured value)
ffmpeg -f s16le -ar 44100 -ac 2 -i /tmp/out/ambient.raw -af ebur128 -f null -
ffmpeg -f s16le -ar 44100 -ac 2 -i /tmp/out/ambient.raw -af "volume=<gain>dB" -c:a aac -b:a 96k -movflags +faststart ambient-loop.m4a
```

## Chant conversion

```bash
ffmpeg -i chant.ogg -af "volume=-2.5dB,afade=t=in:d=0.4,areverse,afade=t=in:d=2.5,areverse" -c:a aac -b:a 96k -movflags +faststart gregorian-chant.m4a
```
